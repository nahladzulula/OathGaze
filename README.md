# OathGaze

OathGaze enables scalable, high-availability security through concurrent, multi-threaded execution of modular components within a self-configuring suite.

With OathGaze, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/OathGaze.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

OathGaze is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
